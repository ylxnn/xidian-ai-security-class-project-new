# 每周课堂汇报

本目录用于保存本组每周汇报的 PPT 和对应原论文 PDF。这是小组自行约定的目录，课程 README 未指定统一路径。

## 已有材料

- [汇报 PPT：MCP 寄生式工具链攻击](MCP寄生式工具链攻击.pptx)
- [对应论文 PDF：2509.06572v5](2509.06572v5.pdf)

汇报日期、汇报人请根据实际情况补充。

## 后续存放方式

以后每次汇报新建一个子目录，例如 `2026-10-XX-主题/`（将 XX 替换为实际日期），在里面放：

- `slides.pptx`：课堂汇报 PPT。
- `paper.pdf`：对应原论文。
- `README.md`：记录汇报日期、汇报人、论文标题和原始链接、简短总结。

材料应提交到本组 Fork 的仓库，和 projects 文件夹并列保存，不放入项目运行时的 data 或 knowledge 目录（这些目录通常被 Git 忽略）。
